# Emergentology Experimental Protocol

## Objective

Test whether the Wright Emergence Functional predicts onset, persistence, or strength of emergent structure better than standard baseline metrics.

## Candidate systems

Recommended first systems:
- coupled oscillators;
- recurrent neural networks;
- cellular automata;
- reaction-diffusion systems;
- multi-agent coordination;
- control systems approaching instability or recovery.

## Primary hypothesis

\[
H_0:
\text{Wright metric adds no predictive value beyond baseline}
\]

versus

\[
H_1:
\text{Wright metric improves prediction of emergent structure}.
\]

## Baselines

Compare against:
- raw entropy;
- mutual information;
- Lyapunov exponents;
- order parameters;
- spectral coherence;
- simple distance-to-attractor measures;
- standard control residuals.

## Required design

- prespecify \(C,S,A,R\);
- freeze coefficients before confirmatory testing;
- separate calibration and confirmatory datasets;
- report effect sizes and uncertainty;
- include ablation of each functional term;
- test robustness across scales and systems;
- use negative controls;
- avoid redefining “emergence” after observing outcomes.

## Strong result

The strongest result would be a single normalized or dimensionless emergence statistic whose threshold predicts persistent structure across multiple unrelated systems.
